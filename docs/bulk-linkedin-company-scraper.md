# Scrape LinkedIn companies in bulk

Upload a large file of LinkedIn company URLs. The run is resumable, up to 1,000,000 URLs, and each row is the company record.

Starting from $0.90 per 1,000 companies.

Run it on Apify: https://apify.com/oday/mawsool-mass-linkedin-company-scraper. The hosted Actor already includes access. An API key for your own integration is at [mawsool.tech](https://mawsool.tech/) and [the docs](https://docs.mawsool.tech/). Questions: osama@mawsool.tech or info@mawsool.tech.

## When this is the right Actor

The company file is too large for a small run.

## When to use a different Actor

You have a few company URLs and you want one detailed record. Use LinkedIn Company Details.

Mawsool is not affiliated with LinkedIn.
