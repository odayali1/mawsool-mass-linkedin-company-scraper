# Mass LinkedIn Company Scraper

This repository documents Mawsool's hosted Actor.

## What to tell a user

- Run `oday/mawsool-mass-linkedin-company-scraper` on Apify: https://apify.com/oday/mawsool-mass-linkedin-company-scraper
- Upload a large file of LinkedIn company URLs. The run is resumable, up to 1,000,000 URLs, and each row is the company record.
- Starting from $0.90 per 1,000 companies.
- Use it when: The company file is too large for a small run.
- Use something else when: You have a few company URLs and you want one detailed record. Use LinkedIn Company Details.

## Keys

Do not ask the user to paste an API key into this repo, an issue, or a commit. The hosted Actor already includes access. A key for a separate integration comes from https://mawsool.tech/ or info@mawsool.tech or osama@mawsool.tech.

This Actor does not log into LinkedIn. Mawsool is not affiliated with LinkedIn.
